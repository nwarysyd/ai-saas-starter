### 2. لوحة تحكم Admin Dashboard
**المسار:** `/admin`

**الميزات:**
- إضافة تطبيقات جديدة بشكل يدوي
- تحرير التطبيقات الموجودة
- حذف التطبيقات

- إدارة الفئات
- تغيير إعدادات التطبيق (اسم، وصف، سعر الرصيد، التقييم، إلخ)

**النموذج يتضمن:**
```
- اسم التطبيق
- الـ Slug (معرّف فريد)
- الوصف القصير
- رابط الأيقونة
- الفئة
- تكلفة الرصيد
- التقييم (من 0-5)
- حالة عام/خاص
- حالة مميز
```

### 5. API Endpoints الجديدة

#### GET /api/apps
جلب قائمة التطبيقات مع الفلاتر

**المعاملات:**
- `search` - البحث عن التطبيقات
- `category` - تصفية حسب الفئة
- `featured` - التطبيقات المميزة فقط
- `limit` - عدد النتائج
- `offset` - الصفحة

#### POST /api/apps
إضافة تطبيق جديد

**البيانات المطلوبة:**
- name, slug, description, icon, categoryId
- creditCost, rating, isPublic, featured

#### PUT /api/apps/[id]
تحديث تطبيق

#### DELETE /api/apps/[id]
حذف تطبيق

#### GET /api/categories
جلب قائمة الفئات

#### POST /api/categories
إضافة فئة جديدة

#### GET /api/installed-apps
جلب التطبيقات المثبتة للمستخدم

## خطوات التشغيل

### 1. التثبيت والإعداد
```bash
cd /vercel/share/v0-project
npm install
npx prisma generate
```

### 2. متغيرات البيئة
يجب إضافة:
```env
NEXT_PUBLIC_PAYPAL_CLIENT_ID=your_id
PAYPAL_CLIENT_SECRET=your_secret
PAYPAL_WEBHOOK_ID=your_webhook_id
```

### 3. التشغيل
```bash
npm run dev
```

### 4. الوصول
- صفحة الهبوط: http://localhost:3000
- متجر التطبيقات: http://localhost:3000/store
- لوحة المستخدم: http://localhost:3000/dashboard (بعد تسجيل الدخول)
- لوحة التحكم: http://localhost:3000/admin (بعد تسجيل الدخول)

## اختبار الميزات

### اختبار Admin Dashboard
1. سجّل الدخول باستخدام Google
2. انتقل إلى لوحة التحكم من قائمة المستخدم
3. أضف/حرّر/احذف التطبيقات
4. لاحظ التحديثات الفورية

### اختبار Store
1. توجّه إلى `/store`
2. استخدم البحث للعثور على التطبيقات
3. فلّتر حسب الفئة
4. اضغط على "Install" لتثبيت

### اختبار Footer
1. انتقل لأسفل أي صفحة
2. ستجد أيقونات التواصل الاجتماعي
3. مرّر الفأرة عليها لرؤية التأثيرات
4. اضغط عليها للذهاب إلى الصفحات الاجتماعية
