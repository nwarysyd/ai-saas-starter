## اختبارات API

### GET /api/apps
- [ ] جلب قائمة التطبيقات
- [ ] البحث بمعامل `search`
- [ ] التصفية بمعامل `category`
- [ ] استخدام `featured=true` لجلب التطبيقات المميزة فقط
- [ ] استخدام `limit` و `offset` للتصفحة
- [ ] جلب بيانات الفئة مع التطبيق

### POST /api/apps
- [ ] إضافة تطبيق جديد
- [ ] التحقق من البيانات المطلوبة
- [ ] معالجة الأخطاء

### PUT /api/apps/[id]
- [ ] تحديث تطبيق موجود
- [ ] التحقق من الأخطاء (تطبيق غير موجود)
- [ ] تحديث البيانات بشكل صحيح

### DELETE /api/apps/[id]
- [ ] حذف تطبيق موجود
- [ ] التحقق من الأخطاء (تطبيق غير موجود)
- [ ] عدم ظهور التطبيق المحذوف

### GET /api/categories
- [ ] جلب قائمة الفئات
- [ ] ترتيب الفئات حسب الأولوية

### GET /api/installed-apps
- [ ] جلب التطبيقات المثبتة للمستخدم
- [ ] عدم إرجاع التطبيقات المثبتة لمستخدمين آخرين
- [ ] التحقق من الدخول (رسالة خطأ للمستخدم غير المسجل)
